# 🎂 Happy Birthday Website

A beautiful and interactive birthday website created with love for **Nandhu**. This project includes a countdown timer, memories section, love notes, a birthday letter, and an animated cake-cutting experience.

## ✨ Features

- 🎉 Elegant Birthday Landing Page
- ⏳ Live Birthday Countdown
- 📸 Memories Gallery
- 💌 Interactive Letter Section
- ❤️ 100 Reasons Why You're Special
- 🎂 Animated Cake Cutting Experience
- ✨ Glassmorphism UI Design
- 📱 Fully Responsive (Mobile, Tablet & Desktop)
- 🎊 Confetti Celebration Effect

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- Google Fonts

## 🚀 How to Run

1. Download or clone the project.
2. Open the project folder.
3. Run `index.html` in any web browser.
